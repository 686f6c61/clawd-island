# Support policy

Claude Island is maintained on a best-effort basis.

## Supported versions

Only the latest published release receives routine compatibility and security
fixes. Development builds and older releases may be unsupported. A security
advisory may identify additional affected or fixed versions.

## What free support includes

- Public documentation and release notes.
- Best-effort issue triage.
- Security updates for the current release when reasonably possible.
- No guaranteed response or resolution time.

Free use does not include an SLA, guaranteed compatibility with every Claude
Code or macOS release, data recovery, remote administration, custom builds, or
on-call support.

## Requests

- Security vulnerabilities: follow [SECURITY.md](SECURITY.md).
- Licensing or private contact: `686f6c61@00b.tech`.
- Ordinary defects and feature requests: use the public issue tracker once the
  repository is available, after removing secrets and private project data.

Paid support and enterprise terms are not currently offered.
